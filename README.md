**[Tierstack](https://github.com/bigmike12/tierstack)** is an independent billing and payment-orchestration platform I designed and built for software businesses.

It includes:

- Provider-agnostic payment adapters for **Paystack and Flutterwave**
- Subscription lifecycle management, proration, trials and grace periods
- Invoicing and payment-attempt tracking
- Usage metering and entitlement resolution
- Idempotency and signed webhook processing
- Background workers and retry/dunning workflows
- **92-endpoint REST API**
- Node/TypeScript and Python SDKs
- PostgreSQL, Redis, Prisma, BullMQ and Fastify
- **400+ unit tests** plus API conformance and end-to-end verification

> I’m particularly interested in infrastructure that solves real payment and billing problems in African markets.
