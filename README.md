## Selected Work

### 💳 Tierstack — Billing & Payment Infrastructure

**Private project · available for technical walkthrough**

A billing and payment-orchestration platform designed for African software businesses. Tierstack treats the billing engine as the system of record while payment providers act as rails.

The system includes subscriptions, invoices, proration, usage metering, entitlements, idempotency, signed webhooks, provider adapters, background workers, dunning, a customer billing portal and Node/Python SDKs.

**Stack:** TypeScript · Fastify · PostgreSQL · Prisma · Redis · BullMQ · Next.js
